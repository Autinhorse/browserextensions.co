Claude conversations are often long, structured, and worth keeping - research, writing, and coding sessions you'll want to reference later. Here's how to save them as files you own.

## Method 1: Claude's built-in options

- **Account data export.** Claude lets you request an export of your account data from settings. It's a full archive, good for backup but not for saving a single chat quickly.
- **Copy and paste.** You can select the conversation and paste it into a document, but pasting frequently drops formatting, lists, and code styling.

## Method 2: Print to PDF

`Ctrl/Cmd + P` → **Save as PDF** works well for a short chat that fits on screen. With very long conversations it occasionally misses content scrolled out of view, or catches a stray interface control.

## Method 3: One-click export with AI Chat Snapper

[AI Chat Snapper](/products/ai-chat-snapper) turns a Claude conversation into a clean file in one click:

1. Open the Claude conversation at claude.ai.
2. Click the AI Chat Snapper icon.
3. Choose **PDF, Word, PNG, Markdown, TXT, or JSON**.
4. Save it locally, or send it to Notion, Google Docs, or Obsidian.

Claude's headings, lists, and code blocks all survive the export. The same extension works with [9 other assistants](/docs/ai-chat-snapper/supported-platforms) too.

## Saving Claude chats as notes

If you keep a knowledge base, export to [Markdown](/docs/ai-chat-snapper/export-to-markdown) and drop the chat straight into Obsidian or Notion - see [how to save AI chats offline](/guides/how-to-save-ai-chats-offline).
