AI Chat Snapper exports chats from **10 AI assistants**, so you only learn one tool no matter which assistant you use.

## Supported AI assistants

| Assistant | Notes |
| --- | --- |
| **ChatGPT** | OpenAI's assistant at chatgpt.com |
| **Claude** | Anthropic's assistant at claude.ai |
| **Gemini** | Google's assistant at gemini.google.com |
| **Grok** | xAI's assistant |
| **Mistral (Le Chat)** | Mistral's assistant |
| **DeepSeek** | DeepSeek's assistant |
| **Qwen** | Alibaba's assistant |
| **Kimi** | Moonshot's assistant |
| **Doubao** | ByteDance's assistant |
| **Perplexity** | Answer engine - export research threads |

## How it works across platforms

The export flow is the same everywhere: open a conversation, click the extension, pick a format, and save. Because the extension reads the conversation directly on the page, the export preserves headings, lists, and code formatting regardless of which assistant you used.

## Interface languages

AI Chat Snapper's own interface is available in 10 languages, so you can use it in your preferred language.
