## Is my chat uploaded anywhere?

For local exports, no. Files are generated on your device and the extension can run fully offline. Optional Notion, Google Docs, and Obsidian exports only run when you choose them, and go directly from your browser to that destination.

## Do I need an account?

No. AI Chat Snapper works without an account or sign-in for local exports.

## Which AI assistants are supported?

Ten: ChatGPT, Claude, Gemini, Grok, Mistral, DeepSeek, Qwen, Kimi, Doubao, and Perplexity. See [Supported Platforms](/docs/ai-chat-snapper/supported-platforms).

## Which formats can I export to?

Six: PDF, Word, PNG, Markdown, TXT, and JSON. Each has its own guide under **Export formats** in the sidebar.

## Does exporting keep code blocks and formatting?

Yes. Because the extension reads the conversation directly, headings, lists, and code blocks stay formatted in the export - unlike copy-paste or browser printing, which often lose styling.

## Which browsers does it work in?

Chrome and other Chromium-based browsers, including Edge, Brave, and Arc.
