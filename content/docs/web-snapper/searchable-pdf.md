A PDF is the most portable way to keep a page: it looks the same on every device, prints cleanly, and is easy to attach to an email or a case file. Web Snapper's PDF export goes further than a flat screenshot — the text inside stays real, so you can select it, search it, and copy from it later.

## Export a page to PDF

1. Open the page you want to keep.
2. Click the Web Snapper icon.
3. Choose the PDF format.
4. Pick a capture mode if needed, then save the file.

## Text you can actually search

The text on the page stays selectable and searchable in the finished PDF — in any language. Chinese, Arabic, Hindi, mixed scripts: it all carries through, so you can search a long document for a single phrase or copy a quote without retyping it. Links on the page remain clickable too, so references and citations still work inside the export.

## Highlights become real annotations

Any highlights you add in the on-page editor export as native, editable PDF annotations — not pixels baked into an image. That means they show up in the comment or annotation panel of any standard PDF reader, and a reviewer can adjust or remove them later. The rest of your markup — notes, drawings, and redactions — is preserved in the export as well.

## Choose your paper

Different pages call for different layouts, so you can set the page geometry before saving:

- **Paper size** — A4, Letter, or fit-to-content, which sizes a single continuous page to the captured content instead of slicing it into sheets.
- **Orientation** — portrait or landscape, whichever frames the page better.

Fit-to-content is handy for long, scrolling pages you want to read end to end; A4 or Letter is the right call when the PDF needs to print on standard paper.
